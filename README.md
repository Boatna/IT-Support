# 🛠️ IT Support Helpdesk & IT Control Center

ระบบแจ้งซ่อมและบริหารจัดการงานเทคโนโลยีสารสนเทศ (IT Service Desk & Control Center)
เชื่อมต่อฐานข้อมูล Google Sheets ผ่าน Google Apps Script Web App แบบ Real-time

---

## 📁 โครงสร้างไฟล์ในระบบ

| ไฟล์ | หน้าที่ |
| :--- | :--- |
| **`Code.gs`** | Backend (Google Apps Script): API, จัดการ Sheet, อัปโหลดรูป Drive, ส่งอีเมล, ตรวจสอบ PIN/Session Token |
| **`Index.html`** + `app.js` | หน้าพนักงาน (ฟอร์มแจ้งซ่อม / แนบรูปภาพทุกหมวดหมู่ / ค้นหาพนักงานอัตโนมัติ / ติดตามสถานะงาน) |
| **`dashboard.html`** + `dashboard.js` | IT Control Center (ล็อกอิน PIN รายคน, สถิติ, ตารางจัดการ Ticket, ระบบข้อความสำเร็จรูป Quick Notes) |
| **`style.css`** | สไตล์การแสดงผล Responsive สำหรับหน้าพนักงาน และ Dark Theme สำหรับ Dashboard |
| **`manifest.json`** | ไฟล์ตั้งค่า Progressive Web App (PWA) สำหรับติดตั้งแอปลงในมือถือและคอมพิวเตอร์ |
| **`sw.js`** | Service Worker สำหรับ PWA แคชไฟล์ระบบให้เปิดใช้งานได้สะดวกรวดเร็ว |
| **`icon-192.png`**, **`icon-512.png`** | ไอคอนแอปพลิเคชันความละเอียดสูงสำหรับหน้าจอโฮมและเดสก์ท็อป |

## 🚀 ฟีเจอร์ใหม่ที่ได้รับการเพิ่มเข้ามา

### 1. 📷 แนบรูปภาพประกอบได้ทุกหมวดหมู่ปัญหา
- **หมวดหมู่ทั่วไป (Hardware, Software, Network, อื่นๆ):** พนักงานสามารถถ่ายรูปหรือแนบภาพหน้าจอ Error, อาการเสีย หรือสภาพอุปกรณ์ส่งมาได้ (แบบไม่บังคับ)
- **หมวดขอเครื่องใหม่ (Request_New_PC):** บังคับแนบรูปถ่ายเครื่องเก่าเพื่อประกอบการพิจารณาตามเดิม
- **ระบบบีบอัดรูปอัตโนมัติ:** บีบอัดภาพผ่าน HTML5 Canvas ให้ขนาดกะทัดรัดก่อนอัปโหลดขึ้น Google Drive ประหยัดเน็ตและบันทึกไว
- **แสดงรูปใน IT Control Center:** ช่าง IT สามารถคลิกดูรูปตัวอย่าง ขยายภาพแบบ Popup หรือเปิดดูไฟล์ต้นฉบับบน Google Drive ได้ทันทีในทุกหมวดหมู่งาน

### 2. ⚡ ระบบข้อความบันทึกสำเร็จรูป (Quick Notes)
- ในหน้าจัดการ Ticket ของช่าง IT เพิ่มปุ่มลัดสำหรับใส่บันทึกการแก้ไขด่วนด้วยการคลิกเพียง 1 ครั้ง:
  - `✅ ติดตั้งโปรแกรมแล้ว` — ใส่ข้อความ *"ติดตั้ง/อัปเดตโปรแกรมเรียบร้อยแล้ว ทดสอบใช้งานได้ปกติ"* พร้อมปรับสถานะเป็น **เสร็จสิ้น** อัตโนมัติ
  - `✅ เปลี่ยนอุปกรณ์แล้ว` — ใส่ข้อความ *"เปลี่ยนอุปกรณ์/สายสัญญาณใหม่ ทดสอบใช้งานได้ปกติ"* พร้อมปรับสถานะเป็น **เสร็จสิ้น** อัตโนมัติ
  - `🌐 เครือข่ายปกติ` — ใส่ข้อความ *"แก้ไขระบบเครือข่าย/การเชื่อมต่อเรียบร้อย ใช้งานได้ปกติ"* พร้อมปรับสถานะเป็น **เสร็จสิ้น** อัตโนมัติ
  - `📦 รับเครื่องเข้าเช็ก` — ใส่ข้อความ *"นำเครื่องเข้าตรวจเช็กที่ฝ่าย IT อยู่ระหว่างดำเนินการ"*
  - `🚚 ส่งซ่อมภายนอก` — ใส่ข้อความ *"ส่งซ่อมบริษัทภายนอก รอรับเครื่องคืนประมาณ 3-5 วันทำการ"*
  - `🔍 ไม่พบปัญหา` — ใส่ข้อความ *"ตรวจสอบแล้วไม่พบปัญหาผิดปกติ / ใช้งานได้ตามปกติ"*

### 3. 📲 ติดตั้งเป็น Web App (PWA) บนมือถือและคอมพิวเตอร์
- รองรับการติดตั้งลงบนหน้าจอโฮม (Home Screen) ของมือถือ หรือแถบ Taskbar ของคอมพิวเตอร์เสมือนเป็นแอปพลิเคชันจริง
- **วิธีติดตั้ง:**
  - **บนคอมพิวเตอร์ (Google Chrome / Microsoft Edge):** จะมีแบนเนอร์แจ้งเตือน หรือกดไอคอนติดตั้งแอป ⊕ ที่แถบขวาบนของ URL bar
  - **บน Android:** กดปุ่ม **"ติดตั้งแอป"** บนแบนเนอร์ หรือกดเมนู 3 จุดของเบราว์เซอร์ ▸ เลือก *"ติดตั้งแอป (Install App)"*
  - **บน iPhone / iPad (Safari):** กดปุ่ม Share (สี่เหลี่ยมลูกศรชี้ขึ้น) ▸ เลือก *"เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)"*

### 4. 🛒 ติดตามการจัดซื้อเครื่องใหม่ (เลขที่ PR / PO และเลข Asset เครื่องใหม่)
- **ระบบบันทึกแบบกระชับ (Lightweight):** จัดเก็บข้อมูลลงใน Google Sheet `IT_Requests` โดยตรงในคอลัมน์ 24–26 (X, Y, Z) ไม่ต้องสร้างหน้าระบบจัดซื้อที่ซับซ้อนเกินความจำเป็น
- **จัดการผ่าน IT Control Center:**
  - ใน Modal จัดการ Ticket ของช่าง มีกล่อง **"ข้อมูลจัดซื้อ (PR / PO / Asset ใหม่)"**
  - ใส่ **เลขที่ PR** (เช่น PR67-0012) เมื่อเปิดขอซื้อ
  - ใส่ **เลขที่ PO** (เช่น PO67-0045) เมื่อใบสั่งซื้อออก
  - ใส่ **เลข Asset เครื่องใหม่** (เช่น IE-IT-PC-0123) เมื่อได้รับเครื่องใหม่มาถึง
  - มีปุ่ม Quick Notes ช่วยบันทึกด่วน: `📝 เปิด PR แล้ว` และ `💻 ได้รับเครื่องใหม่`
- **ป้าย Badge บนตาราง:** แสดงข้อมูล PR / PO / Asset ใหม่เป็น Badge สีเหลืองในตารางงานของ IT ทันที
- **พนักงานตรวจสอบได้:** ในหน้าติดตามสถานะของพนักงาน (`loadMyTickets`) จะแสดง Badge PR / PO / Asset ใหม่ให้ผู้ขอเครื่องทราบความคืบหน้า
- **แจ้งเตือนทางอีเมลอัตโนมัติ:** เมื่อช่างบันทึกข้อมูล PR, PO หรือเลข Asset ใหม่ ระบบจะแนบรายละเอียดเข้าในอีเมลอัปเดตสถานะที่ส่งถึงผู้แจ้งด้วย

## 📊 โครงสร้างชีตใน Google Sheet

| ชีต | รายละเอียด |
| :--- | :--- |
| **`IT_Requests`** | เก็บข้อมูล Ticket ทั้งหมด **26 คอลัมน์ (A - Z)** ไม่กระโดดข้ามแถวว่าง จัดเก็บรหัสพนักงานเป็น Text ป้องกันเลข 0 หาย (คอลัมน์ 24: `เลขที่ PR`, 25: `เลขที่ PO`, 26: `เลข Asset ใหม่`) |
| **`Employee_Data`** | รายชื่อพนักงาน อ่านจากหัวคอลัมน์: รหัสพนักงาน, ชื่อ-นามสกุล, แผนก, ตำแหน่ง, Plant, อีเมล, เบอร์โทร, เลขทะเบียน Asset |
| **`IT_Staff`** | รายชื่อทีมช่าง IT และ **PIN รายคน** — A = ชื่อช่าง, B = PIN, C = สถานะ (`ใช้งาน`/`ปิด`), D = Email (ส่งอีเมลแจ้งเตือนงานใหม่ให้ช่างทุกคนที่เปิดใช้งาน) |

## ⚡ วิธีตั้งค่า Google Sheet อัตโนมัติ (คลิกเดียวจบ)

เมื่อนำโค้ด `Code.gs` ไปวางใน Google Apps Script แล้ว:
1. ด้านบนของหน้าจอ Apps Script ข้างปุ่ม **"เรียกใช้" (Run)** จะมีกล่องเลือกฟังก์ชัน ให้เลือกฟังก์ชัน **`setupSheet`**
2. กดปุ่ม **"เรียกใช้" (Run)** (หากมีหน้าต่างถามสิทธิ์การเข้าถึง ให้กดยอมรับสิทธิ์)
3. ระบบจะสร้างและจัดระเบียบชีตทั้ง 3 ชีต (`IT_Requests`, `IT_Staff`, `Employee_Data`) ใส่สีหัวตาราง ตรึงแถว และตั้งฟอร์แมตข้อมูลให้ครบ 26 คอลัมน์ (A - Z) อัตโนมัติทันที
4. นอกจากนี้ เมื่อเปิดไฟล์ Google Sheet จะมีเมนูใหม่ด้านบน: **`🛠️ ระบบ IT Support ▸ ⚡ ตั้งค่าชีตทั้งหมดอัตโนมัติ (Setup Sheets)`** สามารถกดสั่งตั้งค่าจากหน้า Google Sheet ได้เช่นกัน

## 🛠️ วิธี Deploy โค้ดขึ้น Google Apps Script

1. เปิดสเปรดชีต Google Sheet ▸ ไปที่ **ส่วนขยาย (Extensions) ▸ Apps Script**
2. คัดลอกโค้ดจากไฟล์ **`Code.gs`** ทั้งหมดไปวางแทนที่โค้ดเดิม แล้วกด **บันทึก (Save)**
3. กด **การทำให้ใช้งานได้ (Deploy)** ▸ **การจัดการการทำให้ใช้งานได้ (Manage deployments)**
4. กดปุ่มแก้ไข (✏️) ▸ เลือกเวอร์ชัน: **เวอร์ชันใหม่ (New version)** ▸ กด **ทำให้ใช้งานได้ (Deploy)**
5. ตรวจสอบว่า `API_URL` บรรทัดแรกของ `app.js` และ `dashboard.js` ตรงกับ Web App URL ที่ได้
